###  BOT
---
A sleek and responsive AI chatbot built with React.js, powered by OpenAI GPT-3.5. This project enables real-time conversation with the OpenAI model via an intuitive user interface.

---
### ✨ Features

    🔹 Chat with OpenAI's GPT-3.5 model

    🔹 Modern React UI with smooth UX

    🔹 Handles loading and error states gracefully

    🔹 Easily configurable with your own OpenAI API key
---

### 🛠️ Technologies Used

    React.js (with Hooks)

    OpenAI API (gpt-3.5-turbo)

    CSS (or Tailwind/Styled Components, if used)

    Axios / Fetch for API calls
---
### 📦 Installation
```bash
git clone https://github.com/f4izR/BOT.git
```
```
cd react-ai-chatbot
```
```
npm install
```
---
### 🔑 Setup

Create a .env file in the root of the project:

VITE_OPENAI_API_KEY=your_openai_api_key

    ⚠️ Keep your API key secure! Never expose it in the client if you're deploying publicly.
---
### 📱 Usage

```
npm run dev
```
Visit: http://localhost:5173

Start chatting with your AI assistant!
